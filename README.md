# プログラミングでワールドツアー！🌍

小学校の授業で使える、**ブロックを並べて迷路をクリアするプログラミング学習ゲーム**です。

成蹊のマスコット「けやっきー」を動かして、世界各地・宇宙のゴールを目指します（全20ステージ）。

---

## まずここを開く

| だれ向け | なにができるか | リンク |
|----------|----------------|--------|
| **子ども（児童）** | ゲームで遊ぶ・進捗を保存する | https://educoder-lab.github.io/labyrinth/ |
| **先生** | クラスの進み具合を見る・データを消す・テストプレイ | https://educoder-lab.github.io/labyrinth/teacher.html |

| **先生（事前研修）** | 進め方・声かけ・チェックリスト | https://educoder-lab.github.io/labyrinth/docs/研修スライド-小学3年.html |

> すでに公開サイトとして動いています。普段の授業では上のリンクを使えばOKです。

## このアプリでできること（全体像）

1. **子どもがログインする**（学年・組・出席番号）
2. **つづきからのときはステージを選んで再開できる**
3. **ブロックを並べてけやっきーを動かす**
4. **ゴールすると進捗がクラウドに保存される**
5. **先生が教師画面で、誰がどこまで進んだか確認できる**
6. **必要なら先生が生徒データやクラスデータを削除できる**

個人名は使いません。番号だけで管理します。

## 子ども向け：遊び方

### ログイン

1. 児童用ページを開く
2. **学年・組・出席番号**を選ぶ
3. 「はじめる！」を押す
4. 前に遊んだ記録があるときは  
   - **つづきから** … つぎに **ステージ選択画面**が出るので、遊びたいステージを選ぶ  
     （クリア済みは ✅、パーフェクトは 👑。おすすめのステージが最初に選ばれている）  
   - **はじめから** … 進捗をリセットしてステージ1から  

保存したくないときは「まずはためす（ほぞんなし）」でも遊べます（クラウドには残りません）。

### ゲームの基本操作

| 操作 | 意味 |
|------|------|
| つかえるブロックをクリック／ドラッグ | プログラムに追加 |
| プログラム内でドラッグ | 順番を入れ替え |
| つかえるブロックの場所に戻す | そのブロックを削除 |
| **うごかす！** | プログラムを実行 |
| **もどす** | けやっきーを最初の位置に戻す（指定ブロックがあるステージはプログラムも最初の状態に戻る） |
| **ぜんぶけす** | プログラムを全部消す |
| **ヒント** | ステージの考え方を見る |

カベにぶつかったときは **「カベにぶつかった！」** と表示され、原因のブロックが赤く光ります。

### クリアの種類

| 表示 | 意味 |
|------|------|
| ✅ クリア | ゴールできた |
| 👑 パーフェクト | **できるだけ少ないブロック数**でクリア（指定ブロックがあるステージでは、それを消さずにクリア） |

### コースの進み方

- **スタンダードコース（1周目）**  
  - はじめは「すすむ」「まがる」  
  - 後半で「くりかえす」「ゴールするまで」「もし」を段階的に学ぶ  
- **マスターコース（2周目）**  
  - ステージ20クリア後に解禁  
  - 全ブロックが使え、自由に別解へ挑戦できる  

### メダル

長く遊ぶとメダルがもらえます（画面右上の「🏅 メダル」から確認）。

| メダル | 条件 |
|--------|------|
| 🥉 ブロンズ | スタンダード全20クリア |
| 🥈 シルバー | スタンダード全20パーフェクト |
| 🥇 ゴールド | マスター全20クリア |
| 🌈 マスタープラチナ | マスター全20パーフェクト |

## 先生向け：教師画面の使い方

1. [教師用ダッシュボード](https://educoder-lab.github.io/labyrinth/teacher.html) を開く  
2. **教師パスワード**を入力してログイン  
3. 学年・組を選んで「再読み込み」  
4. クラスの進捗表が表示される  

### 表の見方

| 記号 | 意味 |
|------|------|
| ・ | まだクリアしていない |
| ✅ | クリア |
| 👑 | パーフェクト |

### 先生ができること

| ボタン | 内容 |
|--------|------|
| **再読み込み** | 最新の進捗を取得 |
| **クラス行を用意** | 授業前に 1〜30番の空データをまとめて作成（ログインを速く安定させる） |
| **クラスデータ削除** | いま表示している学年・組の進捗をすべて削除 |
| **削除（各行）** | その出席番号の進捗だけ削除 |
| **ゲームをひらく（テストプレイ）** | 先生用の試しプレイ（進捗は保存されない） |

> 削除は取り消せません。確認ダイアログが出ます。

## 小学3年の授業で使う場合（目安）

### ねらい

コードを暗記することではなく、

- 命令は **上から順番** に実行される
- 「おく → うごかす → みる → なおす」を自分で回す
- 失敗しても直してみる  

という **考え方** を育てます。

### どこまで進めるか（目安）

| レベル | ステージ | 内容 |
|--------|----------|------|
| 全員 | 1〜3 | すすむの順番 |
| 余力 | 4〜5 | みぎ／ひだり |
| 発展 | 6以降 | 無理に進めなくてよい |

### 45分の流れ（例）

1. **0–5分** 導入（ねらい・画面の見方）※授業スライドを投影  
2. **5–10分** ログイン ※一斉にせず、班ごとにずらすと安心  
3. **10–15分** みんなでステージ1  
4. **15–35分** 個人活動（ステージ2〜5）  
5. **35–40分** 工夫の共有  
6. **40–45分** 振り返り  

### 役割分担

- **担任**：ねらいの説明、声かけ、見取り、振り返り  
- **ICT支援員**：端末・ログイン・操作トラブル・保存確認  

### スライド

| 資料 | 使い方 |
|------|--------|
| [授業スライド](https://educoder-lab.github.io/labyrinth/docs/授業スライド-小学3年.html) | 児童に見せる投影用（`N`キーで先生メモ） |

## よくある質問

**Q. 進捗はどこに保存されますか？**  
A. クラウド（Supabase）に保存されます。同じ学年・組・番号でログインすると続きから遊べます。

**Q. 名前は保存されますか？**  
A. しません。学年・組・出席番号だけです。

**Q. クラス30人で同時にログインしても大丈夫？**  
A. 基本的には大丈夫です。学校のWi‑Fiが混むときは、班ごとに少しずらすと安心です。

**Q. 先生パスワードを忘れました**  
A. 管理者に連絡してください。システム側の設定（`app_config`）で変更できます。画面上にはパスワードを表示しません。

**Q. パソコンで試しに開きたい**  
A. 公開URLを使うのが簡単です。開発者が手元で確認するときは次でも開けます。

```bash
npx --yes serve -l 8080
```

ブラウザで `http://localhost:8080/` を開きます。

## 管理者・開発者向け（初期設定）

普段の授業利用では不要です。サーバー設定をやり直す人向けです。

### 仕組み（ざっくり）

- ゲーム画面（HTML）  
- 進捗の保存先（Supabase）  
- 先生画面（進捗確認・削除）  

の3つで動いています。

### 初回セットアップ

1. [Supabase](https://supabase.com/) でプロジェクトを作る  
2. SQL Editor で [`supabase/schema.sql`](supabase/schema.sql) を実行する  
3. Project Settings → API で  
   - Project URL  
   - Publishable key  
   をコピーする  
4. [`config.js`](config.js) に貼る  

```js
window.LABYRINTH_CONFIG = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'sb_publishable_...'
};
```

5. 児童ログイン・保存・教師ログインを確認する  

### 追加パッチ（すでに運用中のとき）

| ファイル | 目的 |
|----------|------|
| [`supabase/patch-password.sql`](supabase/patch-password.sql) | 教師パスワード更新 |
| [`supabase/patch-delete-student.sql`](supabase/patch-delete-student.sql) | 削除機能の追加 |

Supabase の SQL Editor で実行します。

### 設定項目（`app_config`）

| 項目 | 意味 |
|------|------|
| `teacherPassword` | 教師ログインのパスワード |
| `allowedGrades` | 使える学年 |
| `maxStudentNo` | 出席番号の上限 |
| `maxClass` | 組の上限 |

### 主なファイル

| ファイル | 役割 |
|----------|------|
| `index.html` | 児童用ゲーム |
| `teacher.html` | 教師用画面 |
| `config.js` | クラウド接続設定 |
| `js/classroom-api.js` | ログイン・保存・削除の通信 |
| `supabase/schema.sql` | データベース定義 |
| `docs/` | 授業・研修スライド |

### 旧スプレッドシートからの移行

CSVがある場合:

```bash
node supabase/migrate-from-csv.mjs "progress.csv"
```
